# Lua · Roblox — справочник и дорожная карта

Русскоязычный статический сайт-справочник: язык **Lua/Luau**, программирование в **Roblox Studio**, работа с **ИИ**, командная разработка, монетизация и налоги в Польше. Без сборщиков и фреймворков — чистые HTML/CSS/JS, бесплатно деплоится на **GitHub Pages**.

## Запуск локально

```bash
npm install            # только для проверки ответов (fengari)
npm run check          # собрать индекс + проверить, что все ответы проходят свои тесты
npm run serve          # http://localhost:8080  (любой статический сервер подойдёт)
```

Открывать `index.html` двойным кликом (`file://`) нельзя: браузер блокирует `fetch` и Web Worker. Нужен http-сервер.

## Деплой на GitHub Pages (бесплатно)

1. Запушьте репозиторий на GitHub (ветка `main`).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Любой push в `main` запускает `.github/workflows/pages.yml`: собирает индекс, прогоняет проверку ответов и публикует сайт. Адрес: `https://<пользователь>.github.io/<репозиторий>/`.

Альтернатива без Actions: **Source: Deploy from a branch → `main` / `(root)`** — сайт полностью статический, `manifest.json` и `search.json` уже закоммичены (после правки контента выполните `npm run build` и закоммитьте их).

Сайт использует только относительные пути и хэш-маршрутизацию (`#/page-id`), поэтому работает и в подпапке репозитория, и на своём домене без дополнительных настроек. Файл `.nojekyll` уже добавлен.

## Как добавить страницу

Создайте `content/<section>-NN-имя.md`:

```markdown
---
title: Заголовок
section: lua            # start | lua | roblox | ai | team | money | biz | tools
order: 17
summary: Одна строка для карточки и поиска
time: 20
level: Новичок
---

## Раздел
Текст, **жирный**, `код`, [ссылка](https://…), внутренняя ссылка [[lua-01-start]] или [[lua-01-start|свой текст]].
```

### Разметка

| Что | Как |
|---|---|
| Запускаемый код | <code>```lua run</code> … <code>```</code> |
| Код без запуска | <code>```lua</code> (подсветка), также `bash`, `json`, `yaml`, `text` |
| Врезки | `:::tip` / `:::note` / `:::warn` / `:::danger` / `:::ai` / `:::money` + заголовок в той же строке, закрытие `:::` |
| Сворачиваемый блок | `:::details Заголовок` … `:::` |
| Этап дорожной карты | `:::stage 1 \| Название \| срок` … `:::` |
| Чек-лист (сохраняется) | `- [ ] пункт` |
| Компонент | `{{success-calc}}`, `{{income-calc}}`, `{{api-table}}` на отдельной строке |

Задание с автопроверкой (внешний контейнер на **4** двоеточия, вложенные — на 3):

````markdown
::::task mid Название
Условие…

:::starter
```lua
local function f(x)
end
```
:::
:::test
```lua
assert(f(2) == 4)
```
:::
:::hint
Подсказка
:::
:::answer
```lua
local function f(x) return x * 2 end
```
Пояснение
:::
::::
````

Тест выполняется **после** кода пользователя в том же чанке (видит его `local`-переменные). `npm run verify` проверяет, что ответ проходит тест, а стартовый код — нет.

Тест-вопрос:

````markdown
::::quiz
Вопрос?
- [ ] неверно
- [x] верно
Пояснение (показывается после правильного ответа)
::::
````

## Ограничения встроенного запуска Lua

Это **Lua 5.3 (Fengari)** + небольшой слой совместимости, а не настоящий Luau: нет `game`, `Instance`, `Vector3`, типов, `continue`, интерполяции строк. Такие примеры в уроках показаны без кнопки запуска — проверяйте их в Roblox Studio. `task.wait` не ждёт по-настоящему (виртуальное время).

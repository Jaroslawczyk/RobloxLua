## 5 категорий инструментов

| Категория | Примеры | Сильные стороны | Слабые стороны |
|---|---|---|---|
| **1. Встроенный в Studio** | Roblox Assistant (чат и агентные возможности внутри Studio) | знает Studio, видит вашу сцену, не надо настраивать, бесплатный/включён в платформу (условия смотрите в документации) | возможности и лимиты ограничены платформой; хуже для больших рефакторингов |
| **2. ИИ внутри редактора** | Cursor, VS Code + Copilot/другие расширения, Windsurf, Zed | автодополнение, правки по диффам, быстро, видит весь репозиторий | нужен внешний редактор + Rojo |
| **3. CLI-/агентные кодеры** | Claude Code, Codex CLI, Gemini CLI, аналоги | сами читают файлы, запускают линтеры/тесты, делают многошаговые задачи | расходуют токены; нужен контроль и права |
| **4. Чат-боты** | Claude, ChatGPT, Gemini, DeepSeek и др. в браузере | отлично для идей, разборов, объяснений, генерации отдельных модулей | вручную копировать код; нет доступа к проекту |
| **5. Генераторы ассетов** | 3D (в т. ч. встроенные в Studio), изображения/иконки, звук/музыка, текст/локализация | быстрый прототип арта и озвучки | надо проверять лицензии, правила Roblox и качество |

## Как ИИ «подключается» к Roblox Studio

Studio сама не имеет API «из любого ИИ». Есть четыре практических пути (подробно — в [[ai-02-studio-setup]]):

1. **Встроенный Assistant** — самый простой старт, без настроек.
2. **Rojo + внешний редактор + ИИ-агент (рекомендуется для серьёзных проектов)** — код живёт в файлах на диске, ИИ правит файлы, Rojo синхронизирует в Studio, а Git хранит историю.
3. **MCP-сервер Roblox Studio** — ИИ-клиент (Claude, Cursor и др.) получает «руки» *внутри открытой Studio*: может читать дерево объектов, править скрипты, запускать тест. Есть встроенный в Studio вариант (по документации Roblox) и open-source реализация.
4. **Плагины** — ИИ помогает *писать* плагины для Studio (автоматизация рутины), а также есть готовые плагины с интеграцией ИИ.

## Что отдавать ИИ, а что делать самому

| Отдавайте ИИ | Делайте сами / проверяйте особенно тщательно |
|---|---|
| шаблонный код (меню, магазин, инвентарь, яйца/питомцы) | архитектуру и границы доверия клиент/сервер |
| тесты, линтер-правки, рефакторинг | сохранения (DataStore), деньги, ProcessReceipt |
| объяснение чужого кода и ошибок | античит и безопасность |
| генерацию конфигов (таблицы предметов, диалоги) | баланс экономики и геймдизайн |
| локализацию, тексты, описания | финальный «вкус»: ощущение игры, UI |
| документацию, README, комментарии | юридические вопросы, налоги |

## Правило «трёх проверок»

Любой код от ИИ проходит: **(1) линтер/анализатор → (2) запуск в Studio → (3) человеческий взгляд на логику, особенно на сервер/деньги**. Подробный процесс — в [[ai-05-no-errors]].

## Безопасность и приватность

- Не отправляйте ИИ секреты: API-ключи Open Cloud, токены, пароли — только через переменные окружения/секреты CI, и добавьте их в `.gitignore`.
- Прочитайте политику данных провайдера (обучение на ваших данных, срок хранения), особенно для корпоративных/платных планов.
- Агентам с доступом к терминалу давайте **минимальные права**: чтение репозитория, запуск линтера/тестов; опасные команды (`rm`, `git push --force`, публикация) — только после вашего подтверждения.
- Не вставляйте код/модели, лицензия которых запрещает копирование, и проверяйте сгенерированные ассеты на соответствие правилам Roblox (авторские права, контент).

## Откуда берутся расходы

Стоимость запроса ≈ **входные токены × цена входа + выходные токены × цена выхода**. В агентных сессиях главный источник трат — **повторная отправка контекста**: на каждом шаге модель получает всю переписку и файлы заново (частично дешевле благодаря кэшированию).

| Источник расхода | Как проявляется | Как лечить |
|---|---|---|
| **Раздутый контекст** | в диалоге 100K+ токенов, каждая реплика дорогая | чаще начинать новую сессию, сжимать историю |
| **«Весь проект в промпт»** | вставили 40 файлов «на всякий случай» | давать только нужные файлы/функции |
| **Лишние итерации** | модель угадывает API, вы чините, она снова | дать точный контекст и текст ошибки сразу |
| **Дорогая модель на простое** | флагман форматирует код | маршрутизация (см. [[ai-03-models-by-task]]) |
| **Длинные ответы** | модель переписывает файл целиком | просить diff/только изменённые функции |
| **Агент ходит по кругу** | не может исправить, повторяет | остановить, дать подсказку, сменить подход/модель |
| **Большие логи** | вставили 5000 строк Output | отфильтровать: первая ошибка + 20 строк |

## Контекстное окно: что это и почему важно

- У модели есть «окно» — сколько токенов она видит за раз (в него входят: системные правила, файлы, история, результаты инструментов, её ответ).
- Чем больше окно занято, тем дороже каждый ход и тем **хуже качество** (модель «теряет» детали в длинном контексте).
- Токен ≈ 3–4 символа английского текста; для русского и кода обычно больше токенов на символ. Ориентир: 1000 строк Luau ≈ 10–15K токенов.

## 15 приёмов экономии

1. **Правила один раз, в файле проекта.** `AGENTS.md`/`CLAUDE.md` на 40–80 строк (не 500!): стек, команды, запреты, структура. Не повторяйте это в каждом сообщении.
2. **План дёшево, реализация потом.** Сначала попросите план (3–7 пунктов), поправьте его словами — и лишь затем код. Исправить план в 100 раз дешевле, чем переписать модуль.
3. **Маленькие задачи.** «Реализуй модуль CurrencyService по этому API» вместо «сделай всю игру». Один модуль — одна сессия.
4. **Диффы, а не файлы целиком.** Просите: «покажи только изменённые функции» / «верни patch».
5. **Точный контекст.** Дайте: нужный файл(ы), строку ошибки, ожидаемое поведение. Не «не работает, посмотри».
6. **Новая сессия на новую тему.** Закончили модуль — начните с чистого контекста (команды вроде `/clear`, `/compact` в CLI-агентах; в чатах — новый диалог с кратким резюме).
7. **Резюме вместо истории.** Когда диалог длинный, попросите «кратко резюмируй решения и состояние», вставьте в новый чат.
8. **Типы и интерфейсы как «сжатый контекст».** Файл `Types.luau` + сигнатуры функций объясняют проект лучше, чем 2000 строк реализации.
9. **Поиск вместо чтения.** Агент должен использовать grep/поиск по символам, а не читать каждый файл.
10. **Кэшируйте стабильную часть.** Провайдеры дают **prompt caching**: неизменный префикс промпта (правила, большие справочники) читается из кэша заметно дешевле. Держите стабильные части в начале, а меняющиеся — в конце; не «ломайте» префикс мелкими правками. (Условия кэша у каждого провайдера свои — смотрите их документацию.)
11. **Batch-режим для массовых задач.** Для неспешной пакетной работы (перевод 500 строк, генерация описаний) у провайдеров есть batch-API со скидкой — нет смысла платить за мгновенный ответ.
12. **Дешёвая модель для первой версии.** Класс B делает черновик, A — улучшает. Для простых случаев — достаточно B.
13. **Автоматические проверки вместо вашего времени.** Подключите StyLua/Selene/luau-lsp, чтобы агент сам видел ошибки: каждая ваша ручная итерация («ты сломал X») — дороже.
14. **Ограничивайте формат ответа.** «Без вступлений, без объяснений, только код» там, где объяснение не нужно; и наоборот — «объясни в 5 пунктах» там, где нужно.
15. **Следите за расходом.** В CLI-агентах есть команды показа стоимости/контекста; в кабинете провайдера — дашборд и лимиты. Установите **лимит расходов** (hard cap) и алерт.

## Типичные дорогие ошибки

:::warn
- **Вставка всей игры в чат** с вопросом «найди баг».
- **Бесконечный чат**: «исправь», «исправь ещё» на 80 репликах.
- **Агент без границ**: «улучши проект» — он будет читать и менять всё подряд.
- **Просьба «перепиши красивее»** для рабочего кода: огромные диффы и риск новых багов.
- **Ожидание, что ИИ знает свежее API**: он может выдумать свойство. Дайте выдержку из документации (см. ниже).
:::

## Как «давать документацию» дёшево

Вместо «найди в интернете» дайте **выжимку**:

```markdown
### Контекст API (выжимка из docs)
- MarketplaceService.ProcessReceipt — единственный колбэк на сервер; возвращает Enum.ProductPurchaseDecision.
- receiptInfo: PurchaseId, PlayerId, ProductId, CurrencySpent.
- Идемпотентность: хранить PurchaseId.
```

Храните такие выжимки в `docs/api/*.md` — агент подтягивает их по необходимости. Можно просить ИИ **один раз** подготовить выжимку из официальной страницы и сохранить в репозитории.

## Шаблон рабочего дня (экономный)

1. **Утро (5 мин):** запустить агента, прочитать `TODO.md`/задачи, выбрать 1–3 задачи.
2. **Задача → план (флагман/сильная модель, 1–2 мин)** → правки плана.
3. **Реализация (рабочая модель, агент)** с ограничением: «меняй только файлы X, Y; запусти stylua + selene».
4. **Проверка:** Play в Studio, смотрим Output. Ошибки — в агент **целиком** (текст + строка).
5. **Ревью (другая модель, по чек-листу безопасности)** — только для серверных/денежных частей.
6. **Коммит** (понятное сообщение), закрыть сессию (`/clear`).
7. **Вечер:** обновить `AGENTS.md`, если ИИ повторял одну ошибку («не использовать wait()») — **правило в файл**, а не в чат.

## Расчёт бюджета (шаблон)

```text
Токены/сессия ≈ (контекст_правил + файлы + история) × число_ходов  (с кэшем — дешевле)
Стоимость/день ≈ сессии × (вход × цена_вх + выход × цена_вых)
Пример (условный): 6 сессий × (150K вх + 15K вых) ≈ 0.9M вх + 0.09M вых
  при $3/$15 за 1M → 2.7 + 1.35 ≈ $4/день → ~$100/мес
```

Реальные цифры зависят от модели, кэша и привычек. Измеряйте неделю и оптимизируйте узкое место.

:::money Сравнение: токены vs время
Час вашего времени (даже условно 5–10 $) чаще дороже сотен тысяч токенов. Экономить надо **не там, где дешёвая модель споткнётся и заставит вас чинить**, а на пустых тратах: огромный контекст, бесконечные диалоги, флагман для форматирования.
:::

## Локальные модели для рутины

Открытые модели (семейства Qwen-Coder, DeepSeek-Coder, Llama/Mistral и др.) можно запускать у себя (Ollama, LM Studio, llama.cpp) — токены бесплатны, но нужна видеокарта/ОЗУ, а качество ниже топовых моделей на сложных задачах. Подходят для: массового форматирования текстов, генерации описаний, первичного ревью, приватного кода. Не используйте для критичной серверной логики без проверки сильной моделью.

## Задания

::::task easy Бюджет на месяц (чистый Lua)
Напишите `monthlyCost(sessionsPerDay, inputTokensPerSession, outputTokensPerSession, priceIn, priceOut, days)` — стоимость за месяц, где цены за 1 млн токенов.

:::starter
```lua
local function monthlyCost(sessionsPerDay, inTok, outTok, priceIn, priceOut, days)
end
```
:::
:::test
```lua
local c = monthlyCost(6, 150000, 15000, 3, 15, 30)
assert(math.abs(c - 6 * 30 * (0.45 + 0.225)) < 1e-6, "c=" .. c)
assert(monthlyCost(0, 100, 100, 3, 15, 30) == 0)
```
:::
:::answer
```lua
local function monthlyCost(sessionsPerDay, inTok, outTok, priceIn, priceOut, days)
  local perSession = inTok / 1e6 * priceIn + outTok / 1e6 * priceOut
  return perSession * sessionsPerDay * days
end
```
:::

::::task mid Выжимка диалога (чистый Lua)
Эмуляция «сжатия контекста»: `compact(messages, keepLast, budgetChars)` — принимает массив строк-сообщений; оставляет последние `keepLast` сообщений полностью, а более ранние заменяет **одним** сообщением `"[summary: N сообщений]"` (N — число замененных). Если все сообщения вместе короче `budgetChars` — вернуть массив без изменений.

:::starter
```lua
local function compact(messages, keepLast, budgetChars)
end
```
:::
:::test
```lua
local m = {"aaaa", "bbbb", "cccc", "dddd", "eeee"}
local same = compact(m, 2, 1000)
assert(#same == 5)
local r = compact(m, 2, 10)
assert(#r == 3 and r[1] == "[summary: 3 сообщений]" and r[2] == "dddd" and r[3] == "eeee")
local r2 = compact({"x"}, 2, 0)
assert(#r2 == 1 and r2[1] == "x")
```
:::
:::answer
```lua
local function compact(messages, keepLast, budgetChars)
  local total = 0
  for _, m in ipairs(messages) do
    total += #m
  end
  if total <= budgetChars or #messages <= keepLast then
    return messages
  end
  local cut = #messages - keepLast
  local out = {"[summary: " .. cut .. " сообщений]"}
  for i = cut + 1, #messages do
    table.insert(out, messages[i])
  end
  return out
end
```
В реальных инструментах «сводку» пишет сама модель, но принцип тот же.
:::

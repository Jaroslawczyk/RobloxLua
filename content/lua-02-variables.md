## Переменная — это имя для значения

```lua run
local score = 10          -- число
local name = "Аня"        -- строка
local alive = true        -- булево значение
local nothing = nil       -- «ничего»

print(score, name, alive, nothing)
```

Ключевое слово **`local`** создаёт локальную переменную — она живёт только в своём блоке кода (`do … end`, функции, цикле, `if`).

:::danger Всегда пишите local
Без `local` переменная становится **глобальной**: она видна из любого места, медленнее и легко вызывает трудноуловимые баги (две части кода случайно используют одно имя). В Roblox глобальные переменные скрипта — один из частых источников ошибок. Правило: **любая переменная и функция — `local`**, если нет веской причины иначе.
:::

## Восемь типов Luau

| Тип | Пример | Проверка |
|---|---|---|
| `nil` | `nil` | `type(x) == "nil"` |
| `boolean` | `true`, `false` | |
| `number` | `42`, `3.14`, `1e3`, `0xFF`, `0b101` | |
| `string` | `"текст"`, `'текст'` | |
| `table` | `{1, 2, 3}`, `{name = "A"}` | |
| `function` | `function() end` | |
| `thread` | `coroutine.create(f)` | корутины, урок 12 |
| `userdata` | объекты движка (`Instance`, `Vector3`…) | в Roblox — `typeof(x)` |

Узнать тип: `type(x)` в обычном Lua, и **`typeof(x)`** в Roblox — он понимает типы движка (`"Vector3"`, `"Instance"`, `"CFrame"` …).

```lua run
print(type(10), type("a"), type(true), type(nil), type({}), type(print))
print(typeof(10), typeof({}))
```

:::note Числа
В Luau **все числа — 64-битные числа с плавающей точкой** (double). Отдельного целого типа нет. Точно хранятся целые до 2^53 (≈ 9·10^15). Для денег и счётчиков это обычно достаточно, но при очень больших значениях (в симуляторах!) нужны специальные приёмы — см. «большие числа» в разделе про монетизацию.
:::

## nil — значение «нет значения»

Необъявленная переменная и несуществующий ключ таблицы дают `nil`. Присвоить `nil` — значит «удалить» значение.

```lua run
local t = {a = 1}
print(t.a, t.b)   -- 1  nil
t.a = nil
print(t.a)        -- nil
```

## Истинность: что считается «ложью»

Ложью считаются **только `false` и `nil`**. Всё остальное — истина, включая `0` и пустую строку `""`. (Это отличается от JavaScript и Python!)

```lua run
if 0 then print("0 — это истина") end
if "" then print("пустая строка — тоже истина") end
if not nil then print("nil — ложь") end
```

## Присваивание, несколько значений

```lua run
local a, b, c = 1, 2, 3
a, b = b, a            -- обмен значениями без временной переменной
print(a, b, c)

local x, y = 10        -- y получит nil
print(x, y)
```

## Преобразования типов

```lua run
print(tonumber("42") + 1)          -- 43
print(tonumber("abc"))             -- nil (не число)
print(tonumber("ff", 16))          -- 255 (система счисления)
print(tostring(123) .. "!")        -- "123!"
print("10" + 5)                    -- 15: строка автоматически станет числом
print(10 .. 20)                    -- "1020": оператор .. склеивает как строки
```

:::warn Не полагайтесь на автопреобразование
`"10" + 5` работает, но это скрытая магия. Явно пишите `tonumber(...)` и проверяйте результат на `nil` — особенно для данных, пришедших от игрока.
:::

## Константы и именование

В Luau нет настоящих констант. Договорённость: имена констант пишут `UPPER_SNAKE_CASE`, а остальное — `camelCase` (в Roblox-сообществе также принят `PascalCase` для классов и сервисов). Подробнее — в разделе про стиль.

```lua
local MAX_PLAYERS = 12
local walkSpeed = 16
local PlayerClass = require(script.Player) -- класс/модуль — PascalCase
```

## Задания

::::task easy Обмен значениями
Даны переменные `a = 3` и `b = 8`. Поменяйте их значения местами **одной строкой** так, чтобы после выполнения `a` стало 8, а `b` — 3.

:::starter
```lua
local a = 3
local b = 8
-- ваш код
```
:::
:::test
```lua
assert(a == 8 and b == 3, "a=" .. tostring(a) .. ", b=" .. tostring(b))
```
:::
:::hint
Множественное присваивание: `x, y = y, x`.
:::
:::answer
```lua
local a = 3
local b = 8
a, b = b, a
```
Правая часть вычисляется целиком до присваивания, поэтому временная переменная не нужна.
:::
::::

::::task easy Тип значения
Напишите функцию `describe(v)`, которая возвращает строку `"число"` для чисел, `"строка"` для строк, `"логика"` для `true/false` и `"другое"` для остального.

:::starter
```lua
local function describe(v)
  -- ваш код
end
```
:::
:::test
```lua
assert(describe(5) == "число")
assert(describe("a") == "строка")
assert(describe(false) == "логика")
assert(describe(nil) == "другое")
assert(describe({}) == "другое")
```
:::
:::answer
```lua
local function describe(v)
  local t = type(v)
  if t == "number" then
    return "число"
  elseif t == "string" then
    return "строка"
  elseif t == "boolean" then
    return "логика"
  end
  return "другое"
end
```
:::
::::

::::task mid Безопасное число
Напишите `toNumberOr(s, default)`: если строку `s` можно превратить в число — вернуть число, иначе вернуть `default`.

:::starter
```lua
local function toNumberOr(s, default)
  -- ваш код
end
```
:::
:::test
```lua
assert(toNumberOr("12", 0) == 12)
assert(toNumberOr("abc", 7) == 7)
assert(toNumberOr("", 1) == 1)
assert(toNumberOr("3.5", 0) == 3.5)
```
:::
:::hint
`tonumber` возвращает `nil`, если преобразовать нельзя. Идиома «или значение по умолчанию»: `x or default`.
:::
:::answer
```lua
local function toNumberOr(s, default)
  return tonumber(s) or default
end
```
Осторожно: если бы значение могло быть `false`, `or` заменил бы его — здесь `tonumber` возвращает число или `nil`, так что всё корректно.
:::
::::

- [ ] `"table"`

- [x] `"Vector3"`

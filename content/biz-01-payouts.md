## Цепочка денег

```text
Игрок платит Robux  ─►  Roblox удерживает комиссию платформы  ─►  Вы получаете «Earned Robux»
        │                                                                 │
        │                                           (группа делит между участниками при необходимости)
        ▼                                                                 ▼
  Дополнительно: Creator Rewards (выплаты за вовлечённость/монетизацию),           DevEx: обмен Earned Robux на деньги
  Premium-выплаты, подписки, реклама — по правилам программ                           (по курсу DevEx), выплата через платёжного партнёра
                                                                                      │
                                                                                      ▼
                                                                    Ваш банк/платёжная система ─► налоги вашей страны
```

## Основные источники дохода разработчика

| Источник | Суть |
|---|---|
| **Продажи в игре** (Game Pass, Developer Products, подписки, Private Servers, Paid Access) | Вы получаете часть цены в Robux (после комиссии платформы). Традиционно платформа удерживает 30%, разработчику идёт 70% — проверяйте актуальную схему для каждого типа |
| **Creator Rewards** (с июля 2025 заменила Engagement-Based Payouts) | выплаты за вовлечённость и монетизацию по правилам программы |
| **Подписки Roblox/Premium** | распределяются по вовлечённости/правилам программы |
| **Реклама** | размещения в играх (по правилам рекламных программ) |
| **Продажа UGC-предметов** | отдельная программа и комиссии каталога |

:::note
Часть Robux может находиться в статусе «ожидает» (pending) до зачисления — смотрите баланс в Creator Hub.
:::

## DevEx — вывод Robux в деньги

**Developer Exchange** — программа обмена *заработанных* Robux на реальные деньги.

Типичные условия (проверяйте актуальные):
- Нужен достаточный минимум **Earned Robux** (по Help — 30 000).
- Возрастные/верификационные требования к аккаунту (подтверждение личности, возраст ≥ 13 лет, иногда условия по Premium) — читайте текущий список требований.
- Выплаты проходят через платёжного партнёра (в публичных материалах — **Tipalti**): регистрация, налоговая форма, выбор способа получения (банковский перевод и т.д.; доступность зависит от страны).
- **Комиссии партнёра и конвертация валют** могут уменьшать итоговую сумму.
- Фактическое зачисление — после проверки (дни/недели).

## Налоговая информация при выводе

- Нерезиденты США заполняют форму **W-8BEN** (подтверждение «не US person» и, при необходимости, применение налогового договора между страной и США).
- Roblox переносит работу с налоговыми формами в **Creator Hub → Taxes** (по документации: с 1 ноября 2026 — проверьте актуальность).
- В зависимости от вашей информации в формах, в США **может удерживаться налог** с выплат (0–30%); сверьте с налоговым консультантом, какой статус вам подходит.
- Для Польши важно: сумма выплат — ваш **доход**, и его нужно учитывать у себя (см. [[biz-02-poland-taxes]]); налог, удержанный в США, может быть зачтён по договору об избежании двойного налогообложения.

## Расчёт: от оборота игры до рублей/злотых

Формула:

```text
Оборот в игре (Robux) × (1 − комиссия платформы) = Earned Robux
Earned Robux × курс DevEx (USD/Robux) = USD до комиссий выплат
USD × (1 − комиссии партнёра/конвертации) × курс USD→PLN = PLN до налогов
PLN − налоги/ZUS − расходы = чистый доход
```

```lua run
local function payout(spentRobux, platformFee, devexRate, usdToPln, partnerFee)
  local earned = spentRobux * (1 - platformFee)
  local usd = earned * devexRate
  local netUsd = usd * (1 - partnerFee)
  return earned, netUsd, netUsd * usdToPln
end

local earned, usd, pln = payout(100000, 0.30, 0.0038, 3.7, 0.01)
print(("Earned Robux: %d"):format(earned))
print(("USD: %.2f"):format(usd))
print(("PLN до налогов: %.2f"):format(pln))
```

Интерактивный расчёт, включая налоги Польши, — в [[tools-income-calc]].

## Практические советы

1. **Группа + групповые выплаты** — доходы делятся в Robux между участниками; каждый выводит свою долю на своём аккаунте.
2. **Выводите регулярно, но не «по мелочи»**: комиссии партнёра и конвертация делают мелкие выводы невыгодными.
3. **Храните отчёты** (выписки DevEx, подтверждения платежей, курсы) — они нужны бухгалтеру.
4. **Не покупайте/продаёте Robux или аккаунты вне платформы** — это нарушение и мошенничество.
5. **Резерв на налоги:** при выводе сразу откладывайте 25–35% на налоги и взносы (зависит от вашего режима) — чтобы не оказаться в долгах в конце года.
6. **Рекламу и расходы** планируйте как процент от доходов (например, 20–40% на старте) и пересматривайте по ROI.
7. **Диверсификация:** разные игры/источники — защита от падения одного хита.

::::task easy Доход в USD
Напишите `devexUsd(earnedRobux, rate)` — сумма в долларах. Пример: `devexUsd(30000, 0.0038)` = 114.

:::starter
```lua
local function devexUsd(earnedRobux, rate)
end
```
:::
:::test
```lua
assert(math.abs(devexUsd(30000, 0.0038) - 114) < 1e-9)
assert(devexUsd(0, 0.0038) == 0)
```
:::
:::answer
```lua
local function devexUsd(earnedRobux, rate)
  return earnedRobux * rate
end
```
:::

::::task mid Сколько нужно оборота
Напишите `requiredSpend(targetUsd, platformFee, devexRate)` — сколько Robux должны потратить игроки в игре, чтобы вы получили `targetUsd` до налогов. Округлить вверх.

:::starter
```lua
local function requiredSpend(targetUsd, platformFee, devexRate)
end
```
:::
:::test
```lua
assert(requiredSpend(114, 0.30, 0.0038) == math.ceil(114 / 0.0038 / 0.7))
assert(requiredSpend(0, 0.30, 0.0038) == 0)
local x = requiredSpend(1000, 0.30, 0.0038)
assert(x * 0.7 * 0.0038 >= 1000)
```
:::
:::answer
```lua
local function requiredSpend(targetUsd, platformFee, devexRate)
  return math.ceil(targetUsd / devexRate / (1 - platformFee))
end
```
:::

## Lua и Luau: кто есть кто

**Lua** — компактный скриптовый язык, созданный в 1993 году в Католическом университете Рио-де-Жанейро (PUC-Rio). Его любят за простоту, скорость и лёгкую встраиваемость в другие программы: на Lua пишут расширения игр, роутеров, редакторов.

**Luau** — собственный диалект Roblox. Он вырос из Lua 5.1 и добавил то, что нужно большому проекту:

- **постепенную типизацию** (аннотации типов, режим `--!strict`);
- **быстрый компилятор и виртуальную машину**;
- удобства синтаксиса: `+=`, `continue`, строки с подстановкой `` `Привет, {name}` ``, выражение `if … then … else …`;
- собственные библиотеки (`task`, `buffer`, `table.clone`, `string.split` и др.);
- **песочницу** — безопасное исполнение чужого кода на серверах Roblox.

Когда в документации Roblox пишут «Lua» — почти всегда имеют в виду именно Luau.

:::note Официальные источники
Язык: [luau.org](https://luau.org) (раздел Syntax, Type checking, Performance). База: [Lua 5.1 Reference Manual](https://www.lua.org/manual/5.1/). Roblox: [create.roblox.com/docs](https://create.roblox.com/docs). Мы опираемся на них; детали версий проверяйте там.
:::

## Где запускать код

| Способ | Что нужно | Подходит для |
|---|---|---|
| **Эта страница** (поле с кнопкой ▶) | ничего | первые 10–12 уроков: переменные, циклы, функции, таблицы |
| **Roblox Studio** | бесплатный аккаунт и программа | всё, что связано с игрой: `game`, `Instance`, события |
| Онлайн-демо на [luau.org](https://luau.org) | браузер | проверка именно синтаксиса Luau |
| Локально: Luau CLI / Lune | установка | тесты и инструменты вне Studio |

:::warn Ограничение встроенного запускателя
Код на этом сайте выполняется движком **Lua 5.3 в браузере** (проект Fengari) с небольшим слоем совместимости: есть `print`, `warn`, `typeof`, `task.wait/spawn/delay`, `table.find/clone`, `string.split`, `math.clamp`, а строки вида `x += 1` автоматически превращаются в `x = x + 1`. **Нет**: `game`, `Instance`, `Vector3`, типов, `continue`, строк с `{}`. Такие примеры показаны без кнопки запуска — проверяйте их в Studio.
:::

## Ваша первая программа

```lua run
print("Привет, мир!")
print("2 + 2 =", 2 + 2)
```

`print` выводит значения через табуляцию. В Studio вывод появляется в окне **Output** (View → Output).


## Как устроена программа

Lua выполняет код **сверху вниз, по строкам**. Точки с запятой не обязательны. Пробелы и переносы не важны, но читаемость важна: отступ в 2 или 4 пробела внутри блоков (`if`, `for`, `function`) — стандарт.

```lua run
local name = "Рома"          -- объявили переменную
print("Привет,", name)        -- использовали
print(#name)                  -- длина строки в байтах (кириллица: 2 байта на букву!)
```

:::tip Запомните сразу
В Lua нет скобок `{}` для блоков — блоки закрываются словом `end`. Нумерация в массивах начинается с **1**, а не с 0. Сравнение на «не равно» — `~=`, а не `!=`.
:::

::::task easy Исправьте ошибки
В коде три ошибки синтаксиса. Исправьте так, чтобы программа вывела `Готово` и число `10`.

:::starter

```lua
local a = 5
```

:::

## Проверьте себя

::::quiz
Какой знак означает «не равно» в Lua?
- [ ] `!=`
- [x] `~=`
- [ ] `<>`
- [ ] `=/=`
В Lua «не равно» записывается `~=`. Знак `!=` вызовет синтаксическую ошибку, а `!` вообще не используется (вместо него — `not`).
::::

::::quiz
С какого индекса начинается нумерация элементов массива (таблицы) в Lua?
- [ ] С 0
- [x] С 1
- [ ] С -1
- [ ] Можно выбрать при создании
Нумерация «массивов» в Lua/Luau начинается с 1. Это важно и для `#t`, и для `ipairs`.
::::

::::quiz
Чем Luau отличается от Lua 5.1?
- [ ] Это один и тот же язык
- [x] Luau — расширенный диалект Lua 5.1 с типами, `continue`, `+=` и быстрой VM
- [ ] Luau — это язык для 3D-моделей
Luau — форк Lua 5.1, который развивает Roblox: добавлены типы, удобный синтаксис, оптимизации и песочница.

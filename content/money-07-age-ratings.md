:::warn Правила часто меняются
Возрастные системы Roblox (метки контента, проверка возраста для чата, ограничения функций) обновляются регулярно, в том числе по требованиям регуляторов. Ниже — устройство и практика; **точные пороги и названия** сверяйте в Creator Hub (Experience Guidelines) и [Help Center Roblox](https://en.help.roblox.com). Не юридическая консультация.
:::

## Кто играет

Аудитория Roblox — очень широкая: от детей до взрослых; значительная доля — младше 18. Поэтому платформа требует:
- честно описывать содержимое игры;
- ограничивать то, что не подходит для возраста;
- защищать личные данные и общение.

## Рейтинг контента вашей игры

Для каждой Experience вы заполняете **опросник о содержимом** (Experience Guidelines / Maturity). Он описывает: насилие, кровь, страшные сцены, сленг и крепкие выражения, романтические темы, алкоголь/табак, азартные темы, свободный чат и т.д. По ответам игре присваивается **метка зрелости контента** (в разных версиях системы это градации примерно от «минимальной» до «ограниченной/17+»).

Практика:
- Отвечайте **честно и полно**: заниженная метка — основание для санкций и удаления.
- Меняете игру (добавили хоррор-режим, кровь, свободный чат) — **обновите опросник**.
- Игры с «ограниченным» контентом доступны только **взрослым, прошедшим проверку** (например, подтверждение личности/возраста), и не показываются детям.
- Метка влияет на **охват**: чем строже, тем уже аудитория и меньше рекомендаций.
- Для максимальной аудитории и монетизации выбирайте **семейный контент**.

## Ограничения для игроков и функций (общие принципы)

| Что | Принцип |
|---|---|
| **Чат** | для младших — более строгая фильтрация; общение может быть ограничено или требовать проверки возраста (правила усиливаются) |
| **Голосовой чат** | только для подтверждённого возраста (минимум 13) и при включённой функции в игре |
| **Контент 17+** | только для верифицированных взрослых |
| **Платные случайные предметы** | в некоторых странах запрещены/ограничены, нужна публикация шансов |
| **Реклама/внешние ссылки** | ограничены для детей |
| **Торговля предметами** | может быть доступна только части пользователей |
| **Покупки** | у младших аккаунтов — родительские лимиты и подтверждения |
| **Данные** | особые правила для детей (см. законы ниже) |

## Как узнать ограничения игрока в коде: PolicyService

`PolicyService` возвращает флаги политик для конкретного игрока (по возрасту и стране). Используйте их, чтобы **отключать функции**, а не гадать.

```lua
local PolicyService = game:GetService("PolicyService")

local function getPolicy(player)
  local ok, info = pcall(function()
    return PolicyService:GetPolicyInfoForPlayerAsync(player)
  end)
  if not ok then
    -- безопасное значение по умолчанию: самое строгое
    return { ArePaidRandomItemsRestricted = true, AreAdsAllowed = false, IsPaidItemTradingAllowed = false }
  end
  return info
end

Players.PlayerAdded:Connect(function(player)
  local policy = getPolicy(player)
  player:SetAttribute("CanBuyRandomItems", not policy.ArePaidRandomItemsRestricted)
end)
```

Принципы:
- При ошибке запроса берите **самые строгие** настройки.
- Проверку делайте **на сервере**; клиент только скрывает/показывает UI.
- Набор полей `PolicyInfo` дополняется — смотрите актуальную страницу `PolicyService`.
- Если платные случайные покупки ограничены — **подменяйте их гарантированными** (например, «купить конкретного питомца»).

## Фильтрация текста

Любой текст, введённый игроками и показываемый другим (имена питомцев, табло, сообщения), — через `TextService:FilterStringAsync`/`TextChatService`. Не показывайте непрофильтрованный текст.

```lua
local TextService = game:GetService("TextService")

local function filterFor(fromUserId, text, toPlayer)
  local ok, result = pcall(function()
    local obj = TextService:FilterStringAsync(text, fromUserId)
    return obj:GetChatForUserAsync(toPlayer.UserId)
  end)
  return ok and result or "####"
end
```

## Законы и стандарты (общая картина)

| Регион | Что важно |
|---|---|
| **США — COPPA** | дети до 13 лет: особые правила сбора данных и согласия родителей |
| **ЕС — GDPR (включая правила для детей)** | возраст цифрового согласия устанавливает каждая страна (в диапазоне 13–16; в Польше — 16); минимизация данных |
| **Великобритания — Age Appropriate Design Code** | «лучшие интересы ребёнка» по умолчанию |
| **Южная Корея и ряд стран** | правила для платных случайных предметов (раскрытие шансов) |
| **Китай и др.** | особые ограничения для несовершеннолетних; доступность Roblox зависит от региона |

Практический вывод для небольшой команды: **не собирайте личные данные детей вообще**; работайте только с `UserId` и игровыми данными в DataStore Roblox; не заводите внешние формы/Discord-регистрацию для малолетних без продуманных правил; не просите контакты.

## Дизайн игры «для всех возрастов»

- Избегайте реалистичного насилия, крови, азартных и романтических мотивов, если целитесь в семейную аудиторию.
- Честные описания покупок; никакого давления на детей (таймеры-паника, «последний шанс»).
- Родительский контроль и лимиты платформы **не обходите**.
- Предусмотрите **безопасные настройки по умолчанию** (чат фильтруется, нет приглашений от незнакомцев в приватные чаты).
- Форма обращения в поддержку, быстрые ответы на жалобы.

## Если вам самому меньше 18 лет

- Вывод Robux (DevEx), договоры и бизнес-деятельность имеют **возрастные требования** (платформы и закона вашей страны).
- В Польше несовершеннолетние могут заниматься деятельностью только в рамках закона о дееспособности (часто нужно согласие законного представителя и особый порядок) — проконсультируйтесь; см. [[biz-02-poland-taxes]].
- Для команд: договор с несовершеннолетним участником подписывает законный представитель.

## Чек-лист возрастной безопасности перед релизом

- [ ] Опросник содержимого заполнен честно, метка соответствует игре
- [ ] Нет контента, который выше выбранной метки (крови, романтики, азарта)
- [ ] Весь пользовательский текст фильтруется
- [ ] `PolicyService` учтён: случайные покупки, реклама, торговля
- [ ] Нет сбора личных данных и внешних платежей
- [ ] Голос/чат — только в рамках разрешённого платформой
- [ ] Покупки без давления, шансы раскрыты
- [ ] Есть способ пожаловаться и быстрая реакция

## Задания

::::task mid Безопасные настройки по умолчанию (чистый Lua)
Напишите `resolvePolicy(info)`: `info` — таблица флагов или `nil` (если запрос не удался). Вернуть таблицу `{randomItems, ads, trading}` (булевы — что **разрешено**). Для `nil` всё запрещено. Флаги входа: `ArePaidRandomItemsRestricted`, `AreAdsAllowed`, `IsPaidItemTradingAllowed`; отсутствующий флаг трактуйте строго (запрещено).

:::starter
```lua
local function resolvePolicy(info)
end
```
:::
:::test
```lua
local d = resolvePolicy(nil)
assert(d.randomItems == false and d.ads == false and d.trading == false)
local a = resolvePolicy({ArePaidRandomItemsRestricted = false, AreAdsAllowed = true, IsPaidItemTradingAllowed = true})
assert(a.randomItems == true and a.ads == true and a.trading == true)
local b = resolvePolicy({ArePaidRandomItemsRestricted = true, AreAdsAllowed = true})
assert(b.randomItems == false and b.ads == true and b.trading == false)
local c = resolvePolicy({})
assert(c.randomItems == false)
```
:::
:::answer
```lua
local function resolvePolicy(info)
  if not info then
    return {randomItems = false, ads = false, trading = false}
  end
  return {
    randomItems = info.ArePaidRandomItemsRestricted == false,
    ads = info.AreAdsAllowed == true,
    trading = info.IsPaidItemTradingAllowed == true,
  }
end
```
:::

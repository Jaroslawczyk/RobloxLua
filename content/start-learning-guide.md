## Принципы

1. **Практика важнее чтения.** 30% теории, 70% кода. Каждое новое понятие — сразу пример, который вы запустили и сломали.
2. **Маленькие шаги.** Одна идея → одна задача → результат за 10–20 минут. Большие проекты — только из маленьких кусков.
3. **Ошибки — материал для обучения.** Научитесь читать сообщения об ошибках: имя ошибки, файл:строка, значение. Это 50% навыка.
4. **Повторение через интервалы.** Возвращайтесь к пройденному через 1, 3, 7, 14 дней: решайте 1–2 старых задачи без подсказок.
5. **Проекты ускоряют.** После каждого блока — маленький проект, использующий новое.
6. **Читайте чужой код.** Сначала предскажите результат, затем запустите.
7. **Объясняйте вслух/письменно** (метод «утёнка»): если не можете объяснить — не поняли.
8. **Регулярность > героизм.** 1–2 часа каждый день лучше, чем 10 часов раз в неделю.

## Цикл на каждый урок

```text
Прочитать (10 мин) → Запустить примеры и изменить (10 мин) → Решить задания (30–60 мин)
→ Тест (5 мин) → Записать 3 вывода своими словами → Через день: 1 задача без подсказок
```

## Работа с ИИ как с тьютором

:::ai Правила, которые не дают ИИ «думать за вас»
1. **15 минут сами.** Попробуйте решить, прочитайте ошибку, поэкспериментируйте. Только потом — ИИ.
2. **Просите объяснение, а не готовый код**: «Объясни, почему это падает. Подсказку дай, ответ не показывай».
3. **Просите проверку вашего решения**: «Вот мой код. Найди ошибки и скажи, как улучшить, но не переписывай целиком».
4. **Просите упражнения**: «Дай 3 задачи на циклы по возрастанию сложности, без решений».
5. **Проверяйте ответы ИИ**: запускайте код, сверяйте с документацией. ИИ уверенно ошибается.
6. **Записывайте, что поняли**, а не копируйте решения.
7. **Не копируйте задачи курса в ИИ целиком** — вы потеряете смысл тренировки.
:::

## Если «застряли»

1. Сократите пример до минимального, воспроизводящего проблему.
2. Добавьте `print` и проверьте предположения.
3. Прочитайте ошибку слово в слово.
4. Отойдите на 10 минут.
5. Объясните проблему вслух.
6. Спросите — и запишите решение в свои заметки.

## Задания

::::task easy План на неделю
Составьте свой план на ближайшие 7 дней: какие уроки, сколько времени в день, какой мини-проект. Запишите количество часов в неделю в переменную `hoursPerWeek` (реалистично: от 5 до 20).

:::starter
```lua
local hoursPerWeek = 0
```
:::
:::test
```lua
assert(type(hoursPerWeek) == "number" and hoursPerWeek >= 5 and hoursPerWeek <= 20)
```
:::
:::answer
```lua
local hoursPerWeek = 10
```
Реалистичный план лучше амбициозного: пропущенные дни ломают привычку.
:::
::::

::::task mid Интервальное повторение (чистый Lua)
Напишите `reviewDays(startDay)` → массив дней повторения: `startDay + 1, +3, +7, +14, +30`.

:::starter
```lua
local function reviewDays(startDay)
end
```
:::
:::test
```lua
local r = reviewDays(10)
assert(table.concat(r, ",") == "11,13,17,24,40")
```
:::
:::answer
```lua
local function reviewDays(startDay)
  local result = {}
  for _, offset in ipairs({1, 3, 7, 14, 30}) do
    table.insert(result, startDay + offset)
  end
  return result
end
```
:::
::::

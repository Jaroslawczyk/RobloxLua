## Антипромпты (что НЕ работает)

| Плохо | Почему | Лучше |
|---|---|---|
| «Сделай игру как Adopt Me» | нет границ | список систем и порядок реализации; один модуль за раз |
| «Исправь баг» | нет данных | ошибка + код + ожидание |
| «Улучши код» | бесконечная правка | конкретная цель (читаемость/производительность/безопасность) |
| «Ты всё знаешь про Roblox, пиши идеально» | не повышает точность | правила + проверки + тесты |
| Вставка 3000 строк | дорого и размывает внимание | только релевантные файлы |

## Сохраняйте промпты как «навыки»

Повторяющиеся сценарии (ревью, релиз, добавление питомца) оформляйте как **пользовательские команды/навыки** вашего ИИ-инструмента (в большинстве агентов можно хранить markdown-инструкции в папке проекта) — вы вызываете одну команду, а подробная инструкция подгружается из файла. Это и дешевле, и стабильнее, чем набирать вручную.

::::task mid Шаблонизатор (чистый Lua)
Напишите `render(template, vars)`: подставляет `{{имя}}` из `vars`; отсутствующие переменные оставляет как есть. Пример: `render("Привет, {{name}}! {{x}}", {name="Ann"})` → `"Привет, Ann! {{x}}"`.

:::starter
```lua
local function render(template, vars)
end
```
:::
:::test
```lua
assert(render("Привет, {{name}}! {{x}}", {name = "Ann"}) == "Привет, Ann! {{x}}")
assert(render("{{a}}{{a}}", {a = 1}) == "11")
assert(render("нет", {}) == "нет")
```
:::
:::answer
```lua
local function render(template, vars)
  return (template:gsub("{{(%w+)}}", function(name)
    local v = vars[name]
    if v == nil then
      return nil           -- nil в gsub оставляет исходный текст
    end
    return tostring(v)
  end))
end
```
:::

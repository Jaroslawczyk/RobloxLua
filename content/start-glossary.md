## Язык и программирование

| Термин | Объяснение |
|---|---|
| **Lua** | компактный скриптовый язык, 1993 |
| **Luau** | диалект Lua от Roblox: типы, скорость, `continue`, `+=` |
| **Переменная** | имя для значения (`local x = 1`) |
| **Таблица (table)** | единственная составная структура: массив/словарь/объект |
| **Функция** | блок кода, который можно вызывать; значение первого класса |
| **Замыкание (closure)** | функция + захваченные переменные |
| **Метатаблица** | таблица с правилами поведения другой таблицы (`__index` и др.) |
| **ООП** | объектно-ориентированное программирование (классы, объекты, наследование) |
| **Корутина** | приостанавливаемая функция (кооперативная многозадачность) |
| **pcall** | защищённый вызов: перехватывает ошибку |
| **Модуль** | файл/`ModuleScript`, возвращающий значение; `require` |
| **Типизация (gradual typing)** | постепенные аннотации типов, анализ до запуска |
| **Линтер** | программа, которая находит подозрительный код (Selene) |
| **Форматтер** | автоматически приводит код к стилю (StyLua) |
| **Рефакторинг** | улучшение структуры кода без смены поведения |
| **Идемпотентность** | повторное применение даёт тот же результат (важно для покупок) |
| **Race condition (гонка)** | ошибка из-за порядка/одновременности событий |
| **Утечка памяти** | объекты/подписки не освобождаются и копятся |

## Roblox

| Термин | Объяснение |
|---|---|
| **Studio** | редактор Roblox |
| **Experience** | игра на платформе (бывшее «game») |
| **Place** | карта/уровень внутри Experience |
| **Universe** | контейнер Experience и его настроек (`game.GameId`) |
| **DataModel (`game`)** | корень дерева объектов |
| **Instance** | любой объект движка |
| **Service** | глобальный объект движка (Players, Workspace…) |
| **Script / LocalScript / ModuleScript** | серверный / клиентский / подключаемый скрипт |
| **RunContext** | где выполняется Script: Server/Client/Legacy |
| **Replication (репликация)** | передача состояния с сервера клиентам |
| **RemoteEvent / RemoteFunction** | сетевые события/вызовы клиент↔сервер |
| **Network ownership** | кто считает физику объекта: сервер или клиент |
| **StreamingEnabled** | подгрузка мира частями |
| **Humanoid** | объект здоровья/движения персонажа |
| **CFrame** | положение + поворот |
| **Tag** | ярлык `CollectionService` |
| **Attribute** | пользовательское свойство объекта |
| **DataStore** | облачное хранилище данных игры |
| **Group** | группа Roblox (владелец игры, роли, выплаты) |
| **Team Create** | совместное редактирование в Studio |
| **Creator Hub** | веб-панель разработчика: игры, аналитика, монетизация |
| **Toolbox / Creator Store** | каталог моделей, звуков, плагинов |
| **Plugin** | расширение Studio |
| **Rojo** | синхронизация файлов с Studio |
| **Wally** | менеджер пакетов для Roblox |
| **Open Cloud** | HTTP-API Roblox для автоматизации |

## Монетизация и продукт

| Термин | Объяснение |
|---|---|
| **Robux** | внутриигровая валюта Roblox |
| **Game Pass** | разовая покупка, остаётся навсегда |
| **Developer Product** | многоразовая покупка (валюта, расходники, донат) |
| **ProcessReceipt** | серверный колбэк выдачи товара за Developer Product |
| **Subscription** | регулярная подписка внутри игры |
| **DevEx** | Developer Exchange — вывод Earned Robux в деньги |
| **Earned Robux** | заработанные как разработчик Robux |
| **Creator Rewards** | программа выплат за вовлечённость/монетизацию |
| **CCU** | одновременные игроки (concurrent users) |
| **DAU / MAU** | активные в день / в месяц |
| **Retention (D1/D7/D30)** | доля вернувшихся через 1/7/30 дней |
| **ARPDAU / ARPPU** | доход на активного в день / на платящего |
| **LTV** | суммарная ценность игрока за время жизни |
| **CPI** | стоимость привлечения игрока |
| **Core loop** | основной повторяющийся цикл действий |
| **Sink / Source** | сток / источник валюты в экономике |
| **Rebirth/Prestige** | сброс прогресса ради постоянного бонуса |
| **Live-ops** | постоянное обновление и события в живой игре |
| **FOMO** | страх упустить (инструмент давления; используйте честно) |
| **Pity** | гарантия награды после N неудач |

## ИИ

| Термин | Объяснение |
|---|---|
| **LLM** | большая языковая модель |
| **Токен** | единица текста, за которую платят (≈ 3–4 символа англ.) |
| **Контекст/окно контекста** | сколько текста модель «видит» за раз |
| **Prompt caching** | дешёвое повторное чтение неизменного начала промпта |
| **Агент** | ИИ, который сам читает файлы, запускает команды и правит код |
| **MCP** | протокол подключения инструментов к ИИ-клиентам |
| **Галлюцинация** | уверенный, но выдуманный ответ |
| **Batch API** | пакетная обработка со скидкой |
| **Маршрутизация моделей** | выбор модели под сложность задачи |
| **AGENTS.md / CLAUDE.md** | файл правил проекта для ИИ-агента |

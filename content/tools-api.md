## Как читать записи

| Обозначение | Значение |
|---|---|
| `:Method()` | метод (вызывается через двоеточие: `obj:Method()`) |
| `Property` | свойство (читается/задаётся через точку) |
| `Event` | событие: `obj.Event:Connect(fn)` |
| `Class.new(...)` | конструктор типа данных |
| `(контейнер)` | сервис-хранилище, а не функция |
| **yield** | функция может приостановить поток (сетевой вызов) → оборачивайте в `pcall` и учитывайте ожидание |

Методы с `Async` в имени обычно **yield** и могут завершаться ошибкой — всегда `pcall`.

## Как игроки находят игры

1. **Рекомендации платформы** (главная страница, «Рекомендуем вам», «Похожие игры», раздел Discover).
2. **Поиск** (по названию/ключевым словам).
3. **Друзья** (приглашения, присоединение).
4. **Внешний трафик**: YouTube, TikTok, Twitter/X, Discord, Telegram, Reddit.
5. **Платная реклама** (Roblox Ads, спонсорские размещения).

Алгоритм рекомендаций (описывается Roblox в общих чертах) усиливает игры, которые **вызывают у игроков желание играть дольше и возвращаться**: время сессии, удержание, «лайки», конверсия показов в заходы. Следовательно, рост строится на **качестве первой сессии** и **возвращаемости**.

## Упаковка: иконка, название, описание

| Элемент | Совет |
|---|---|
| **Иконка** | яркая, крупный фокус (один персонаж/предмет), контрастные цвета, минимум текста, читаема в 128×128 |
| **Миниатюры** | 5–10 скриншотов/кадров: цикл, редкие предметы, UI на телефоне; отдельная «ключевая» миниатюра |
| **Название** | короткое, запоминающееся, с ключевым словом жанра; **без обмана** |
| **Описание** | 2–3 предложения про цикл + список обновлений; ключевые слова для поиска |
| **Тэги/жанр** | точно соответствуйте игре |
| **Платформы** | включите телефон/планшет, если игра работает |

## Первые 60 секунд

Для алгоритма и игроков решающие:
- Загрузка < 10–15 секунд (экран загрузки, прелоад ключевых ассетов).
- Первое действие — через 5–10 секунд (не стена текста).
- Первая награда — до 30 секунд.
- Цель понятна без чтения: стрелки, подсветка, анимации.
- Первый «момент радости» — до 2 минут.

## Возвращаемость (retention)

| Приём | Эффект |
|---|---|
| Ежедневные награды | D1–D7 |
| Короткие задания/квесты | цель «на сегодня» |
| Ивенты (по расписанию) | повод вернуться |
| Коллекции/достижения | долгосрочная цель |
| Социальные функции (друзья, гильдии) | связь |
| Обновления каждые 1–2 недели | свежесть |
| Уведомления (внутри игры, Discord) | напоминание (без спама) |

## Реклама на платформе

- **Roblox Ads** — реклама в каталоге/разделах, оплата в Robux. Начинайте с небольших бюджетов, метрика — **стоимость привлечённого игрока** (CPI) и **удержание** привлечённых.
- Рекламировать стоит игру, у которой уже есть приемлемое удержание: иначе вы платите за то, что «утекает».
- Пробуйте несколько иконок и сегментов (возраст/платформа).
- Правило окупаемости: `LTV игрока > CPI × запас (1.3–2)` — иначе реклама убыточна.

```lua run
local function roi(cpi, arpdau, days)
  local ltv = arpdau * days
  return ltv / cpi, ltv
end
local ratio, ltv = roi(0.15, 0.03, 12)
print(("LTV ≈ $%.2f, окупаемость x%.2f"):format(ltv, ratio))
```

## Контент-мейкеры и стримеры

- Игра должна быть **удобна для записи**: яркие моменты, шок-значения, юмор, понятные «челленджи».
- Готовьте **пресс-кит**: логотип, скриншоты, короткое описание, ссылка, список обновлений.
- Связывайтесь с мелкими и средними авторами (их аудитория отзывчивее, цены ниже); предлагайте эксклюзивные предметы/коды для их зрителей.
- Не обещайте и не покупайте «накрутку» — это против правил и опасно для аккаунта.
- Чётко отмечайте спонсорство, если платите (требования законов о рекламе).

## Цикл обновлений

```text
Неделя 1: контент (+1 зона/+10 предметов) + ивент
Неделя 2: баланс, фиксы, QoL (удобства), мини-ивент
Неделя 3: новая механика (мини-игра/режим)
Неделя 4: большой апдейт (раз в месяц) + пост и ролик
```

- Анонсируйте обновления заранее (тизеры), в день релиза — пост + ролик.
- Фиксируйте **changelog** в игре (меню).
- Собирайте обратную связь и **показывайте, что вы её услышали** («По вашей просьбе…»).

## Метрики роста

| Метрика | Вопрос |
|---|---|
| Показы → клики (CTR) | Привлекательна ли иконка/название? |
| Клики → заходы | Не ломаются ли загрузка/страница? |
| D1, D7 | Нравится ли игра? |
| Средняя сессия | Достаточно ли контента? |
| Конверсия в платящих | Предложения понятны и своевременны? |
| ARPDAU | Эффективна ли монетизация? |
| K-фактор (приглашённые другом) | Растёт ли органика? |
| Like ratio | Доверяют ли игроки? |

## Антипаттерны роста

- **Накрутка**: боты, фейковые лайки/посещения — риск блокировки.
- **Кликбейтные названия/иконки**, не соответствующие игре — быстрые дизлайки и отток.
- **Агрессивная реклама без удержания.**
- **Игнор комьюнити.**
- **Редкие и большие обновления** вместо стабильных малых.

::::task mid Серия ежедневных наград (чистый Lua)
Напишите `nextStreak(lastClaimDay, today, currentStreak)`: дни — целые номера. Если `today == lastClaimDay` — вернуть `currentStreak, false` (повторно не выдаётся); если `today == lastClaimDay + 1` — `currentStreak + 1, true`; если пропущены дни — `1, true`; максимум серии 7 (после 7 снова 7).

:::starter
```lua
local function nextStreak(lastClaimDay, today, currentStreak)
end
```
:::
:::test
```lua
local s, ok = nextStreak(10, 10, 3)
assert(s == 3 and ok == false)
s, ok = nextStreak(10, 11, 3)
assert(s == 4 and ok == true)
s, ok = nextStreak(10, 13, 5)
assert(s == 1 and ok == true)
s, ok = nextStreak(10, 11, 7)
assert(s == 7 and ok == true)
```
:::
:::answer
```lua
local function nextStreak(lastClaimDay, today, currentStreak)
  if today == lastClaimDay then
    return currentStreak, false
  elseif today == lastClaimDay + 1 then
    return math.min(7, currentStreak + 1), true
  end
  return 1, true
end
```
В игре «день» вычисляют по серверному времени: `os.time() // 86400` (UTC).
:::

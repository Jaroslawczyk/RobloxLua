Код — только часть игры. Остальное (арт, звук, тексты, рутина в Studio, аналитика) тоже можно ускорить ИИ, если выстроить **пайплайн** и соблюдать правила платформы.

## Карта задач

| Задача | Как ИИ помогает | Ограничения / проверки |
|---|---|---|
| **3D-модели, меши** | генерация мешей по описанию (в т. ч. встроенные в Studio возможности), доработка в Blender | проверять топологию/число треугольников, масштаб, лицензии |
| **Иконки предметов, миниатюры, баннеры** | генераторы изображений; единый «стайлгайд» в промпте | согласованный стиль; без чужих персонажей/брендов; ≥ нужные размеры |
| **Текстуры, материалы** | генерация тайловых текстур, PBR | проверка швов (tiling), размер |
| **UI-дизайн** | идеи макетов, палитры, иконки; код UI по описанию | всегда тестируйте на телефоне |
| **Звук, музыка** | генерация коротких SFX и лупов | **правила аудио Roblox и лицензии**; загрузка через Creator Hub проходит модерацию |
| **Тексты (описания, квесты, диалоги)** | генерация/редактура; локализация | вычитка человеком; без токсичности |
| **Локализация** | перевод таблиц строк (ru/pl/en…) | плейсхолдеры, контекст, длина строк в UI |
| **Конфиги и контент** | предметы, питомцы, квесты, события | валидатор схемы и баланс-чек |
| **Плагины Studio** | пишут плагин под вашу рутину | тест на копии, `ChangeHistoryService` для Undo |
| **Автоматизация (Open Cloud, Lune)** | скрипты публикации, массовых правок, отчётов | ключи только в секретах, минимальные права |
| **Аналитика** | разбор метрик, гипотезы, SQL/таблицы | давайте реальные данные; проверяйте выводы |
| **QA** | генерация тест-кейсов, поиск граничных случаев, чек-листы | не заменяет живой плейтест |
| **Сообщество** | посты, анонсы обновлений, Discord-боты | человеческий тон |

## Пайплайн ассетов (пример: 24 иконки питомцев)

1. **Стайлгайд (1 раз):** «Мультяшные 3D-рендеры на градиентном фоне, мягкие тени, чёткий контур, 512×512, без текста, дружелюбные пропорции». Сохраните как текстовый блок.
2. **Бриф по предмету:** таблица `Id | Описание | Палитра`.
3. **Генерация пачкой** (одна модель, один seed/стиль), отбор лучших.
4. **Постобработка:** фон, размер, имена файлов `Dog.png`.
5. **Загрузка** в Creator Hub (Assets) → получить `rbxassetid`.
6. **Сборка таблицы** `Id → AssetId` (ИИ-скрипт или вручную) → конфиг игры.
7. **Проверка** в игре на телефоне (читабельность иконки 64×64).

## Правила и лицензии (важно!)

:::warn Что нужно соблюдать
- Загружаемые ассеты проходят модерацию; нарушения (авторские права, запрещённый контент) ведут к удалению и наказаниям аккаунта.
- Не используйте чужие персонажи/бренды/музыку без прав — даже «в стиле».
- Проверьте условия **коммерческого** использования результатов у каждого ИИ-сервиса (не все планы разрешают коммерцию).
- Для Toolbox/Creator Store — смотрите лицензию и издателя; не вставляйте бездумно модели с чужими скриптами.
- Соблюдайте возрастные требования и правила Roblox для контента/чата; пользовательский текст фильтруйте через `TextService`/`TextChatService`.
:::

## Плагины Studio с помощью ИИ — конкретные идеи

| Плагин | Польза |
|---|---|
| Массовое переименование/нумерация | `Tile_1…Tile_200` |
| Расстановка по сетке/кругу/пути | быстро собирать уровни |
| Проверка карты | найти части без CanQuery/с огромным размером/с нулевым размером |
| Конвертер цветов | палитра проекта → части выбранного |
| Экспорт данных | сохранить свойства в JSON для баланса |
| Генератор LOD | упростить/объединить |
| Аудит безопасности | найти `Script` в клиентских контейнерах, `require(число)` |

Промпт для ИИ: *«Напиши плагин Roblox Studio (Luau), который <действие> для выделенных объектов (`Selection`). Используй `ChangeHistoryService` для Undo, добавь кнопку на тулбар `My Tools` и небольшой `DockWidgetPluginGui` с настройками. Только актуальное API.»*

Пример аудита (запускается в Command Bar Studio):

```lua
-- найти серверные Script в клиентских контейнерах
for _, container in ipairs({game.StarterGui, game.StarterPack, game.StarterPlayer}) do
  for _, obj in ipairs(container:GetDescendants()) do
    if obj:IsA("Script") and obj.RunContext == Enum.RunContext.Legacy then
      print("Проверьте:", obj:GetFullName())
    end
  end
end
```

## Автоматизация через Open Cloud и Lune

- **Публикация** по команде/CI: `rojo build` → загрузка `.rbxl` через Open Cloud (см. [[team-03-ci-cd]]).
- **Работа с DataStore снаружи**: миграции, выдача компенсаций, чтение статистики (HTTP-запросы к API с ключом).
- **Lune/Node/Python-скрипты**: разбор экспортированных аналитических отчётов, генерация таблиц баланса.

ИИ хорошо пишет такие скрипты — дайте ему документацию эндпоинтов и пример запроса, а **ключи держите в переменных окружения**.

## Использование ИИ в геймдизайне

- **Мозговой штурм** механик и событий (но фильтруйте: ИИ любит «среднее по больнице»).
- **Анализ рынка**: «опиши 10 популярных жанров Roblox и их ключевые циклы» — как отправная точка; проверяйте актуальность по реальным данным (Discover, рейтинги, метрики конкурентов).
- **Баланс**: таблицы времени до уровней, симуляции экономики — результаты проверяйте скриптом.
- **Playtest-протоколы**: список вопросов игрокам, сценарии для тестеров.

## Что *нельзя* автоматизировать до конца

- «Вкус»: ощущение игры, ритм, юмор.
- Решения про деньги/этику монетизации.
- Модерацию и общение с детской аудиторией без человека.
- Финальную проверку безопасности критичных систем.

::::task mid Сопоставление ассетов (чистый Lua)
Напишите `buildAssetMap(ids, uploaded)`: `ids` — массив имён предметов, `uploaded` — массив `{name, assetId}`. Вернуть таблицу `имя → "rbxassetid://" .. assetId` и второй результат — массив имён, для которых иконки не загружены (в порядке `ids`).

:::starter
```lua
local function buildAssetMap(ids, uploaded)
end
```
:::
:::test
```lua
local map, missing = buildAssetMap({"Dog", "Cat", "Bird"}, {{name = "Dog", assetId = 111}, {name = "Bird", assetId = 333}})
assert(map.Dog == "rbxassetid://111" and map.Bird == "rbxassetid://333" and map.Cat == nil)
assert(#missing == 1 and missing[1] == "Cat")
```
:::
:::answer
```lua
local function buildAssetMap(ids, uploaded)
  local byName = {}
  for _, u in ipairs(uploaded) do
    byName[u.name] = "rbxassetid://" .. u.assetId
  end
  local map, missing = {}, {}
  for _, id in ipairs(ids) do
    if byName[id] then
      map[id] = byName[id]
    else
      table.insert(missing, id)
    end
  end
  return map, missing
end
```
:::
